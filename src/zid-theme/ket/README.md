# KET theme for Zid (Vitrin)

Zid's official Growth theme (github.com/zidsa/growth-theme, Oct 2026) with KET's product page.
Everything a store needs (home, categories, cart, checkout, account, search) is Growth's; the
product page is the design of `src/ket-product.html` (the prototype on GitHub Pages) on real Zid data.

## What is KET's

| File | What it is |
| --- | --- |
| `templates/product.jinja` | The KET product page. Zid's working parts are kept as they are: product form, options, custom fields, quantity, add to cart / buy now, preorder, notify-me, Tabby / Tamara, checkout dialog, sticky bar, related products. |
| `components/ket/icons.jinja` | Icons, stars, brand shapes, smile and logo (generated by `ket/make_icons.py` from the prototype). |
| `components/ket/dims.jinja` | The front / side dimension drawings. |
| `assets/ket.css` | The prototype's CSS, scoped under `.ket` (generated by `ket/extract_css.py`) + `ket/overrides.css`. |
| `assets/ket-product.js` | Gallery, delivery date, accordions, count-ups, reveals, dimension drawing, story pin; loads the 3D hero. |
| `assets/ket-hero.js` | The 3D scroll-assembly hero (built from `src/ket-hero`, `npx vite build`, copy `dist/ket-hero.js`). |
| `layout.jinja` | + KET fonts, `ket.css` and `ket-site.js`. |
| `header.jinja`, `components/header-announcement-bar.jinja`, `components/header/search.jinja` | KET header (logo that folds into the smile on scroll, EN / ع button, orange cart count) and the pink scrolling announcement bar. Zid's mobile menu, main menu, search, login / profile, cart badge, gift popup and region dialog are kept. |
| `footer.jinja` | KET footer (pink) on the store's own data: footer link groups, about text, social accounts, phone / email, payment methods, VAT / CR, Saudi Business Center, app links. |
| `assets/ket-site.js` | Header scroll state and the mobile-menu offset, on every page. |
| `layout.schema.json` / `layout.json` | + the "Product page (ket)" settings group (Arabic and English defaults). |
| `locale/ar/LC_MESSAGES/messages.po` | + Arabic for the new labels. |

The prototype stays the design source: after changing its CSS or icons, run
`python3 ket/extract_css.py` and `python3 ket/make_icons.py` (from `src/zid-theme`).

## Per-product content (Zid dashboard → product → custom fields / metafields)

Sections without data are simply not shown, so any product works with no setup.

| Metafield key | Type | Shows |
| --- | --- | --- |
| `model_3d` | file (.glb) or text (URL of a .glb) | The 3D scroll-assembly hero at the top of the page. The model must have three parts named `ChairBase`, `SeatCushion`, `SeatBack` (like `models/tuwaiq-chair.glb`). |
| `width`, `height`, `depth`, `seat_height` | number (cm) | The dimensions section (drawings + table). |
| `story_title`, `story_text` | text (Arabic and English) | The story section (uses the product's first two photos). |

Fields are matched by key, or by English or Arabic name (e.g. "Seat height" or "ارتفاع المقعد").
Other metafields appear under "Details".

## Store-wide settings (theme editor → "Product page (ket)")

3D hero on/off, delivery days (for "order today, delivered by …"), when the stock bar shows,
the three promise cards, "Will it fit?", shipping, returns and care texts — each in Arabic and English.

## Build, preview, upload

```bash
cd src/zid-theme
npm install                 # once
npm run build               # Growth's CSS (assets/styles.css) and JS (assets/dist/)
npx @zidsa/vitrin-cli login # once, with the Zid Partner account
npx @zidsa/vitrin-cli preview <dev-store-id>   # check on a development store
npx @zidsa/vitrin-cli build # → the .zip to upload in the store: Theme Market → Upload Theme
```

`python3 ket/preview.py` renders the product page locally with the prototype's chair as sample
data (open `http://localhost:5178/zid-theme/.preview/` with the "ket" dev server). It skips Zid's
own scripts and styles, so it is only for checking the KET layout and motion.
